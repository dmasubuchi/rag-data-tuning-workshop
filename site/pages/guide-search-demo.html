検索デモ：条件を変えると、検索結果が変わる

このページの目次
  • 前提
  • 1. Python で動かす
  • 2. ポータルで同じ検索をする
  • 3. 何が変わったか
  • つまずいたとき

AI Search だけを使う、短いデモです。人事の採用の文書（インデックス hr-docs）を、同じ質問のまま条件だけ変えて検索します。Python の標準ライブラリだけで動きます。pip も az のサインインも要りません。

前提

  • Repo 直下に .env.local がある（検索だけのキーのメンバーの設定でよい。Azure の準備の 4）
  • 構築する人が、インデックス hr-docs を作ってある（応用（人事）の「最初に1回」）

1. Python で動かす

PowerShell で、Repo の直下で実行します。Enter を押すたびに、次の段へ進みます。

python tools/search_demo.py
  1. キーワード検索「Python の経験」
  2. 欄で絞る（職務経歴書だけ）：件数が減る
  3. 見せてよい人で絞る（採用担当）：全部見える。1と同じ件数
  4. 見せてよい人で絞る（一般社員）：求人票だけ
  5. 並べ直す（セマンティック ランカー）：件数は1と同じで、順番が変わる

各段に、件数と上位5件（文書の名前、種類、点、チャンクの先頭）が出ます。同じ文書が複数回出るのは、検索の単位がチャンクだからです。

自分の質問で試すとき：

python tools/search_demo.py --q "面接の評価"

止まらずに全部表示するとき：--no-pause

  • python が見つからないときは、py に替えます。
  • 検索するだけです。何も作らず、何も変えません。
  • 5 は、セマンティック ランカーを 1 回使います。無料枠は月ごとで、チームの AI Search 全体で使います。
  • 接続先とキーは、Repo 直下の .env.local だけから読みます。

2. ポータルで同じ検索をする

各段に出る JSON を、ポータルに貼ると、同じ結果になります。

  1. Azure ポータルで、AI Search srch-<org>-<team> を開く
  2. 左メニュー「検索管理」の「インデックス」を開き、hr-docs を選ぶ
  3. 「検索エクスプローラー」を開き、「表示」で「JSON ビュー」を選ぶ
  4. Python の画面に出た JSON を貼って、「検索」を選ぶ

3. 何が変わったか

  • 2：filter に kind eq 'resume'。欄の値で絞る
  • 3・4：filter に allowed/any(...)。見てよい人で絞る（権限）。一般社員に見せてよいのは、求人票のチャンクだけ（hr-docs 全体で6チャンク）
  • 5：queryType が semantic。意味の近さで並べ直す

見せてはいけないものは、LLM に渡す前に、検索の絞り込みで外します（応用編のトピック 16）。

つまずいたとき

  • 「.env.local が読めません」と出る：Repo の直下で実行しているか、.env.local があるかを確かめます。
  • 「インデックス hr-docs がありません」と出る：構築する人が、文書の取り込み（python applied/tools/build_hr_index.py）を終えているか確かめます。
  • 5 段目で「エラー 403」と出る：キーが合っていないか、セマンティック ランカーの無料枠（月ごと。チームの AI Search 全体で使う）を使い切っています。1〜4 段が動いているなら、無料枠です。
  • 「キーが合いません」と出る：キーが古くなっています。構築する人が python tools/team.py env --team <チーム> --role member --out member.local.env で作り直し、メンバーに渡し直します。
