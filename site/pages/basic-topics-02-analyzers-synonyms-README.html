02 言い換えと日本語の分かれ方

このページの目次
  • 何を学ぶか
  • 前提
  • 実行するコマンド（このフォルダで）
  • 何を見るか
  • 辞書について

何を学ぶか

  • キーワード検索は、質問と本文を「語」に分けて、同じ語を持つ文書を探す。言い換えた質問は、本文と同じ語を持たないので外れる。
  • 語の分け方（アナライザー）によって、同じ言葉の分かれ方が変わる。ただし、別の言葉（「北海道」と「蝦夷地」）は、どのアナライザーでも同じ語にならない。
  • 辞書（同義語マップ）を作ってつなぐと、言い換えの外れを直せる。ただし言い換えは質問ごとに違うので、先回りして全部を書くのは手間がかかる。辞書なしで意味の近さで当てるのが、次の 03（ベクトル検索）。

前提

  • 01-keyword-search を終えている（武将のインデックスがある）。 なければ、各スクリプトが「どうすればよいか」を出して止まる。先頭の REBUILD = True にすると作り直す。
  • このトピックは、AI Search の管理者キーが要る（Analyze API、辞書の作成）。チームでは構築する人の設定（--role builder）で実行する。メンバーの設定（検索だけのキー）では、「構築する人の設定で実行します」と止まる。

実行するコマンド（このフォルダで）

python compare_analyzers.py
python synonym_map.py
python synonym_map.py --rule "眼球, 目玉"

発展：

python tuning.py

Notebook でも、同じファイルを上から順にセルを実行すれば動く。

何を見るか

  • compare_analyzers.py：アナライザー3つ（ja.microsoft、ja.lucene、standard.lucene）の分かれ方の違い。言い換えの質問3つ（q21、q23、q28）と正解の本文に、共通の語がほとんどないこと。
  • synonym_map.py：用意したルール「北海道, 蝦夷地」で q28（榎本武揚）が上がること。
    • 自分でルールを1行足して試す（例 --rule "眼球, 目玉" で q23 の夏侯惇が上がる）。
    • q21（柴田勝家）は1行では上がりきらない（「器」と「水瓶」、「立てこもった」と「籠城」、「壊して」と「割って」の3行が要る）。
  • tuning.py（発展）：検索の順位を人が調整する仕組み。
    • 語の重み：上杉^3 で上げる、武田^0.2 で下げる（重みは正の数の倍率。1 より小さい重みで、このデータでは下がった）。
    • 項目の重み：名前の項目で当たった武将を重くする（スコアリングプロファイル）。
    • 除外の落とし穴：小早川 -隆景 は、既定の searchMode=any では隆景が外れず、一致が 7件から 149件に増える。all にすると、プロフィールに「隆景」とある秀秋まで消える。確実に外すならフィルター。
    • 一方向の置き換え：データにない呼び名（「第六天魔王」「関白」）を武将に結ぶ。
    • 設定には、検索の要求に付けるもの（語の重み、searchMode、フィルター、使うプロファイルの名前）と、インデックスに持つもの（プロファイルの定義、項目への辞書の割り当て）がある。辞書は項目に割り当てると、検索のたびに指定しなくても効く。

辞書について

  • 辞書の名前は sengoku-synonyms（固定）。同義語マップは AI Search 全体で3つまで（Basic）。ほかの用途で上限まで使っていて作れないときは、案内が出るので、使っていない辞書を消す。
  • 辞書を作る・変えるには、AI Search の管理者キーが要る。チームでは構築する人の設定（python tools/team.py env --role builder）で実行する。メンバーの設定（検索だけのキー）では、始めに「構築する人の設定で実行します」と止まる。
  • ルールを入れ替えた直後は、しばらく古いルールで検索されることがある。スクリプトは確認用の1行（kakunin… で始まる行）を一緒に入れ、効き始めるまで待つ。
  • インデックス・辞書の名前は固定で、スクリプトの始めに1回だけ決める。別の名前を渡すと、辞書やインデックスを変える前に止まる（同じ AI Search の、ほかの辞書やインデックスは変えない）。
  • 後片付け（RESTORE = True）。スクリプトのときは、途中で止まったときも行う。Notebook では、途中で止まったときも最後の「後片付け」のセルを実行する。
    • synonym_map.py：辞書を項目から外す。辞書のルールは、このスクリプトで入れたものが残る。つないだままにすると、このあとのトピックのキーワード検索の順位も変わる。
    • tuning.py：実行前の状態に戻す。使った名前のプロファイルは消す（同じ名前のものが前からあれば、その定義に戻す）。辞書は実行前のルールに戻し（なかったときは消す）、項目へのつなぎも実行前のとおりにする。
