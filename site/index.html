データに着目した RAG の研修

検索の基盤の上にある、データの加工・運営・評価を、手を動かして学びます。

この研修について

何を学ぶか
基盤（Azure AI Search）を作るだけでは、よい検索になりません。基盤の上にある、データの加工・運営・評価を、手を動かして学びます。検索のしかたを変え、結果を数字で測り、直す。この繰り返しを、ホテル・戦国武将・採用の文書で体験します。
RAG の R
R は Retrieve（取ってくる）です。集める、順位を付ける、段階的に探す。この考え方を、基盤を作る段階から意識します。
だれ向けか
Azure の SI パートナー（とくにインフラ寄りの人）、企業の情報システム部門・DX 推進、データ・IR・BI・分析の担当。

始め方

チームで進めます。1人が構築する人（Azure にリソースを作る）、ほかの人はメンバー（検索と読み取り）です。人数は自由です。研修を進める人を進行役、研修に出る人を参加者と呼びます。手順書を、番号の順に進めます。

  1. Windows PC の設定Git・Python・az・VS Code を確かめる
  2. Azure の準備チームの名前を決め、ポータルでリソースを作り、接続の設定 .env.local を作る
  3. ホテルホテルのデータで、Azure AI Search をポータルで作って試す。Cosmos DB のベクトル検索も
  4. 武将基礎編（01〜06）。キーワード検索からベクトル検索、ハイブリッド、答えの生成まで
  5. 応用（人事）応用編（14〜20）と採用アシスタント。採用の文書で、業務の検索を見る
  6. 検索デモ条件を変えると結果が変わるのを、AI Search だけで見る
  7. 進行役の手引き進行役（研修を進める人）向け。開始前の準備、パートの順、各パートで見せるもの、つまずきやすい所
