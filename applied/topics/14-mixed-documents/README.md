# 14 種類の違う文書をまとめて取り込む

手元の Python で、形式の違う5種類の文書を読み、検索の単位（チャンク）に分けます。Azure は使いません。

## 何を学ぶか

- 形式ごとに、読むライブラリとチャンクの切り方が違う
  - PDF（pypdf）：ページごと
  - Word（python-docx）：見出しごと。見出しは「見出し」スタイルでなく、太字の大きな文字のことが多いので、書式で見分ける
  - Excel（openpyxl）：1行を1チャンク。「列名: 値」の形にして、何の数字かが分かるようにする
  - メール（email）：1通を1チャンク。件名・差出人・日時を本文の前に付ける
- スキャンした書類（画像だけの PDF、PNG）は、文字が 0 になる。そこにしか書いていない語は、手元の検索では見つからない

## 前提

- `pip install -r applied/requirements.txt`（Repo 直下で、仮想環境の中で）
- 前のトピックは要りません。Azure も `.env.local` も要りません。

## 実行

```
python read_documents.py
python read_documents.py --term "決済基盤"
```

## 見るところ

1. 23 ファイルの一覧の「文字数」：スキャンの3つだけが 0
2. チャンクの例：Excel の1行、Word の見出し1つ分、メール1通、PDF の1ページ
3. スキャンした書類を、画像のビューアーで開く（人の目には読める）
4. 「入社予定日」（内定承諾書にだけ書いてある語）が 0 件
