# 06 検索結果から答えを作る

## 学ぶこと

- 検索で見つけた上位3件を、プロンプトに貼り付けて、LLM に答えさせる（RAG の最小の形）
- 手でコピーして貼る（手動 RAG）のと、コードで送る（自動の RAG）のは、同じことをしている
- RAG が効くのは、LLM が知らない情報を渡すとき。有名な武将は、検索なしでも答えられることがある

## 前提

- `../04-hybrid-ranker` が終わっていること（武将にベクトルとセマンティックの設定が入っていること。04 のスクリプト自体は何も残さない）
- 足りないときは、`python ../../tools/reset.py --to 06`（スクリプトの先頭の `REBUILD = True`、スクリプトでは `--rebuild` でも作り直せる。Notebook では、作り直したら `REBUILD = False` に戻す。`True` のままだと、実行のたびに作り直す）

## 実行するコマンド（このフォルダで）

必須（この順に）
- `python build_prompt.py`　上位3件でプロンプトを組んで表示する（枠の中をコピーして使える。ランカーを 1 回使う）
- `python generate_answer.py`　同じプロンプトを Azure OpenAI に送って答えさせる（ランカーを 1 回使う）
- `python compare_no_search.py`　検索なしで聞いた答えと並べる（`generate_answer.py` が保存した答えを使えるとき、つまり質問・検索の方式・件数が同じときは、ランカーを使わない。違うとき、`REBUILD = True`（`--rebuild`）のあとは、検索し直すのでランカーを 1 回使う）

質問は、`QUESTION = None` のとき山場の質問（q53）。自分の質問は `--q "…"`。

Notebook でも、同じファイルを上から順にセルで実行できます。`--q` などの引数に当たるものは、先頭の「変えてよい値」のセルの変数（`QUESTION` など）で指定します。
検索の方式 `METHOD` と件数 `TOP_N` は、3つのスクリプトそれぞれの先頭にある。`compare_no_search.py` は、`generate_answer.py` と同じ値のときだけ、その答えを使う。

## 何を見ればよいか

- `build_prompt.py`：「【資料1】… 【質問】…」の形。正解の武将がプロンプトに入ったか
- `generate_answer.py`：答えと、正解の武将
- `compare_no_search.py`：2つの答えを、正解と見比べる。検索なしでも当たるとは限らない
